# PowerBI-like Analytics Tool

A modern, open-source business intelligence and data visualization platform inspired by PowerBI.

## Features

- **Interactive Dashboards**: Create dynamic, real-time dashboards with drag-and-drop functionality
- **Data Connectors**: Connect to multiple data sources (SQL databases, CSV, Excel, APIs, cloud services)
- **Visualizations**: Rich library of charts including bar, line, pie, scatter, maps, gauges, and custom visuals
- **Data Modeling**: Build relationships between datasets with a visual modeler
- **DAX-like Query Language**: Powerful expression language for calculations and measures
- **Real-time Refresh**: Automatic data refresh and live streaming data support
- **Collaboration**: Share dashboards, set permissions, and collaborate with teams
- **Responsive Design**: Mobile-friendly dashboards that work on any device
- **Export & Reporting**: Export to PDF, PowerPoint, or schedule automated reports
- **Embedding**: Embed dashboards in external applications with secure tokens

## Tech Stack

- **Frontend**: React, TypeScript, D3.js, Recharts
- **Backend**: Node.js, Express
- **Database**: PostgreSQL, Redis (caching)
- **Data Processing**: Apache Arrow, DuckDB
- **Deployment**: Docker, Kubernetes-ready

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
